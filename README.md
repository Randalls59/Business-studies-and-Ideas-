# SNAP Tucson Feasibility Lab

A visual, browser-based decision dashboard for testing a Cameroon-inspired **SNAP** beverage concept in Tucson, Arizona.

## Open the dashboard

Once GitHub Pages is enabled for this repository, the live dashboard will be available at:

**https://randalls59.github.io/Business-studies-and-Ideas-/**

## What it does

- Uses official Tucson population, income, food-service sales, climate, university enrollment, and wage baselines.
- Lets the user change average customer spend, daily traffic, ingredient costs, labor, rent, fixed costs, and startup investment with sliders.
- Calculates monthly revenue, operating profit, break-even customers per day, and capital payback.
- Compares beverage-first, burger, and hybrid SNAP formats.
- Ranks starter Tucson districts using clearly labeled planning proxies.
- Runs an optional live competitor scan using current OpenStreetMap listings.
- Produces a **GO — LEAN FORMAT**, **TEST FIRST**, or **NO-GO AT THESE INPUTS** recommendation.

## Important limitation

The dashboard is a planning and validation tool, not a guarantee or lender-ready forecast. Rent, construction, supplier, licensing, tax, and foot-traffic assumptions must be replaced with actual quotes before signing a lease.

## Deployment

The site lives in `docs/index.html`. The workflow at `.github/workflows/pages.yml` publishes it through GitHub Pages whenever the dashboard changes.
